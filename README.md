HomePro – Home Services Landing Page

Overview
HomePro is a modern and responsive landing page designed for a home services platform.
It showcases professional service offerings, highlights company trust and guarantees, and provides an engaging user experience for potential customers.

Features
- Hero section with clear value proposition and call-to-action
- Services showcase section
- Trust & guarantees section
- How-it-works workflow explanation
- Customer testimonials carousel
- FAQ accordion for common questions
- Blog preview section
- Contact-ready footer with essential links

Tech Stack
HTML5 – Semantic page structure
CSS3 – Custom styling with CSS variables
JavaScript (Vanilla) – UI interactions (menu, carousel, accordion)
Google Fonts – Plus Jakarta Sans typography
Font Awesome CDN – Icons
SVG Graphics – Scalable visual elements

Getting Started
open: index.html in your browser.
